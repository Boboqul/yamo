# ЯМО — Полное руководство по языку программирования

**Версия:** 2026.09.24 (Self-Hosted Edition)  
**Тип:** Интерпретируемый язык с русским синтаксисом.  
**Особенность:** Компилятор (лексер, парсер, интерпретатор) написан на самом языке ЯМО.

---

## 🚀 Быстрый старт

1. Распакуйте архив `yamo2026.09.24.zip`.
2. Откройте терминал (CMD или PowerShell) в папке с `yamo.exe`.
3. Создайте файл `программа.ямо`:
   ```ямо
   вывод "Привет, мир!";
   целое число = 10;
   вывод число * 2;
   ```
4. Запустите программу:
   ```bash
   ./yamo.exe программа.ямо
   ```

## 📘 Синтаксис и базовые элементы

### Комментарии
```ямо
// Однострочный комментарий
/* Многострочный
   комментарий */
```

### Типы данных
ЯМО имеет статическую типизацию. Основные типы:
*   `целое` — целые числа (int).
*   `дробное` — вещественные числа (double).
*   `текст` — строки (string).
*   `логическое` — булевы значения (`истина`, `ложь`).
*   `словарь` — ассоциативный массив (ключ-значение).
*   `массив` — упорядоченная коллекция элементов одного типа.

### Объявление переменных
```ямо
целое возраст = 25;
текст имя = "Алексей";
логическое активен = истина;
дробное цена = 19.99;

// Инициализация пустых структур
словарь настройки;
массив список_дел;
```

### Вывод на экран
```ямо
вывод "Текст";
вывод 123;
вывод имя + " лет"; // Конкатенация строк
```

## 🔧 Операторы

### Арифметические
`+` (сложение/конкатенация), `-` (вычитание), `*` (умножение), `/` (деление), `%` (остаток от деления).

### Сравнения
`==` (равно), `!=` (не равно), `<` (меньше), `>` (больше), `<=` (меньше или равно), `>=` (больше или равно).

### Логические
`и` (AND), `или` (OR), `не` (NOT).

> **Важно:** При смешивании типов (например, текст + число) происходит приведение к тексту.

## 🔄 Управление потоком

### Условия
```ямо
если (число > 10) {
    вывод "Больше десяти";
} иначе_если (число == 10) {
    вывод "Ровно десять";
} иначе {
    вывод "Меньше десяти";
}
```

### Циклы

#### Пока (While)
```ямо
целое счетчик = 0;
пока (счетчик < 5) {
    вывод счетчик;
    счетчик = счетчик + 1;
}
```

#### Для (For)
```ямо
для (целое индекс = 0; индекс < 10; индекс = индекс + 1) {
    вывод индекс;
}
```

#### Прерывание цикла
```ямо
пока (истина) {
    если (условие_выхода) { прервать; } // Выход из цикла
    если (условие_пропуска) { продолжить; } // Переход к следующей итерации
}
```

## ⚙️ Функции

Функции позволяют инкапсулировать логику.

### Определение и вызов
```ямо
функция сложить(целое первое, целое второе) {
    вернуть первое + второе;
}

целое результат = сложить(5, 3);
вывод результат; // 8
```

### Без возврата значения
```ямо
функция приветствовать() {
    вывод "Здравствуйте!";
    вернуть; // Ранний выход
}
```

### Рекурсия
```ямо
функция факториал(целое n) {
    если (n <= 1) { вернуть 1; }
    вернуть n * факториал(n - 1);
}
вывод факториал(5); // 120
```

## 🗂 Коллекции

### Массивы
```ямо
массив фрукты = ["яблоко", "банан", "апельсин"];

// Доступ и изменение
вывод фрукты[0]; // яблоко
фрукты[1] = "груша";

// Добавление элемента
добавить(фрукты, "манго");

// Длина массива
вывод длина(фрукты); // 4

// Итерация
для (целое i = 0; i < длина(фрукты); i = i + 1) {
    вывод фрукты[i];
}
```

### Словари
```ямо
словарь пользователь;
пользователь["имя"] = "Иван";
пользователь["возраст"] = 30;

// Доступ
вывод пользователь["имя"]; // Иван

// Проверка наличия ключа
если (содержит_ключ(пользователь, "почта")) {
    вывод пользователь["почта"];
} иначе {
    вывод "Почта не указана";
}

// Получение всех ключей
массив все_ключи = ключи(пользователь);
вывод все_ключи; // ["имя", "возраст"]
```

## 🏛 Объектно-ориентированное программирование (ООП)

ЯМО поддерживает классы и наследование.

### Класс
```ямо
класс Автомобиль {
    текст марка;
    целое год;
    
    функция инициализация(текст m, целое g) {
        марка = m;
        год = g;
    }
    
    функция описание() {
        вернуть марка + " (" + в_текст(год) + ")";
    }
}

новый авто = новый Автомобиль("Toyota", 2020);
вывод авто.описание();
```

### Наследование
```ямо
класс Электрокар расширяет Автомобиль {
    целое запас_хода;
    
    функция зарядить(целое км) {
        запас_хода = запас_хода + км;
    }
}

новый электро = новый Электрокар("Tesla", 2024);
электро.запас_хода = 0;
электро.зарядить(100);
вывод электро.запас_хода; // 100
```

## 📚 Стандартная библиотека (Основные функции)

### Работа со строками
*   `длина(текст)` — возвращает длину строки.
*   `часть(текст, нач, кон)` — подстрока.
*   `вверх(текст)` / `вниз(текст)` — регистр букв.
*   `заменить(текст, старое, новое)` — замена подстрок.
*   `разделить(текст, разделитель)` — разбивает строку в массив.
*   `собрать(массив, разделитель)` — склеивает массив в строку.

### Преобразование типов
*   `в_число(текст)` — конвертация строки в число.
*   `в_текст(число)` — конвертация числа в строку.

### Математика
*   `мин(a, b)`, `макс(a, b)`
*   `округлить(x)` — до ближайшего целого.
*   `целая_часть(x)`, `дробная_часть(x)`
*   `степень(base, exp)`
*   `корень(x)`
*   Тригонометрия (работает в **градусах**): `синус(deg)`, `косинус(deg)`, `тангенс(deg)`.
*   Константы: `пи()`, `е()`.

### Файловые операции
*   `читать_файл(путь)` — возвращает содержимое как текст.
*   `запись_файл(путь, текст)` — записывает текст в файл (перезапись).
*   `дописать_файл(путь, текст)` — добавляет в конец файла.
*   `существует_файл(путь)` — проверка наличия файла.
*   `удалить_файл(путь)` — удаление файла.

### JSON
*   `json_разобрать(текст)` — превращает JSON-строку в словарь/массив.
*   `json_собрать(объект)` — превращает словарь/массив в JSON-строку.

### HTTP (Сеть)
*   `http_получить(url)` — GET запрос, возвращает ответ сервера как текст.
*   `http_отправить(url, тело, метод)` — POST/PUT запросы.

### База данных (SQLite)
*   `бд_открыть(путь)` — открывает базу данных.
*   `бд_запрос(sql)` — выполняет SQL-запрос без возврата данных (INSERT, UPDATE, CREATE).
*   `бд_выбрать(sql)` — выполняет SELECT, возвращает массив словарей.
*   `бд_закрыть()` — закрывает соединение.

### Мета-программирование
*   `выполнить(текст_кода)` — динамически исполняет строку кода на ЯМО.
*   `квазин` — специальная директива, печатающая исходный код текущей программы.

## 🛠 Самохостинг (Как это работает?)

Папка `библиотека/` содержит три файла, которые реализуют компилятор ЯМО на самом языке ЯМО:
1.  **`читатель.ямо`**: Лексер. Разбивает текст программы на токены (слова, символы, числа).
2.  **`составитель.ямо`**: Парсер. Строит из токенов дерево абстрактного синтаксиса (AST).
3.  **`мини_исполнитель.ямо`**: Интерпретатор. Выполняет команды из AST.

Эти файлы доказывают, что язык достаточно мощен для описания собственной архитектуры. Нативный `yamo.exe` используется как быстрый входной шлюз, но логика обработки может быть заменена или расширена редактированием этих `.ямо` файлов.
