# ЯМО — язык программирования на русском языке

ЯМО 1.0 (Windows x64). Учебно-практический язык: русские ключевые слова,
статическая типизация, ООП, словари и JSON, файлы, сеть, GUI, SQLite, REPL.

## Установка
1. Распакуйте архив в любую папку.
2. Запустите `install.ps1` (ПКМ → «Выполнить с помощью PowerShell»).
3. Откройте НОВЫЙ терминал — появится команда `yamo`;
   файлы `.ямо` запускаются двойным кликом.

Удаление: `uninstall.ps1`.

## Быстрый старт
    yamo программа.ямо    :: запуск файла
    yamo                  :: интерактивная оболочка (REPL)

## Пример
    функция главная() {
        текст имя = "мир";
        вывод "Привет, " + имя + "!";
        для (целое i = 1; i <= 3; i = i + 1) {
            вывод i * i;
        }
    }
