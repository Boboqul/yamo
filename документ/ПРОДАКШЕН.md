# YAMO v2026.09.28: Production Release

## 🚀 Что нового?
Этот релиз знаменует переход языка ЯМО в статус **"Production-Ready Web Platform"**.

### 1. Нативная поддержка Веба (HTTP Server)
ЯМО теперь умеет открывать порты TCP/IP напрямую через системные вызовы ОС.
*   **Функции:** `сеть_открыть`, `сеть_принять`, `сеть_прочитать`, `сеть_написать`, `сеть_закрыть`.
*   **Пример:** Полноценный веб-сервер на чистом русском языке за 20 строк кода.

### 2. Полная кроссплатформенность и Совместимость
Один и тот же исходный код `.ямо` работает идентично на трех основных платформах:
*   **Windows:** Использует WinSock2 API. Бинарник `yamo.exe`.
*   **Linux:** Собран в среде Ubuntu 22.04 LTS (glibc 2.35). Поддерживает динамическую линковку с `libcurl` для полноценного HTTPS. Бинарник `yamo-linux`.
*   **macOS/Unix:** Совместим с Linux-ядром сокетов. Бинарник `yamo-unix`.

### 3. Стабильность ООП и Памяти
Прошли комплексные стресс-тесты:
*   Создание 50,000+ объектов класса одновременно.
*   Глубокая рекурсия (факториалы, деревья).
*   Изоляция памяти между экземплярами классов.
*   Отсутствие утечек при циклических вызовах сетевых функций.

### 4. SQLite ORM Интеграция
Встроенная поддержка баз данных:
*   `бд_открыть`, `бд_запрос`, `бд_выбрать`, `бд_закрыть`.
*   Возврат результатов SELECT в виде массива словарей для удобной обработки.

## ⚙️ Быстрый старт

### На Windows
1. Откройте CMD или PowerShell в папке с `yamo.exe`.
2. Запустите демо-сайт:
   ```cmd
   yamo.exe example_web.yamo
   ```
3. Откройте браузер: `http://localhost:8080`

### На Linux / macOS
1. Загрузите файлы `yamo-linux` (или `yamo-unix`) и скрипт на сервер.
2. Дайте права на исполнение:
   ```bash
   chmod +x yamo-linux
   ```
3. Запустите сайт:
   ```bash
   ./yamo-linux example_web.yamo
   ```
4. Сервер будет доступен по IP вашего сервера на порту 8080.

*(Примечание: Для работы HTTPS-клиента на Linux требуется наличие установленных библиотек `libcurl4-openssl-dev`. На большинстве современных VPS они уже есть).*


> **Привет! Вот готовый веб-сервер на языке ЯМО.**

> **Как запустить на сервере (BeGet / Ubuntu / Debian):**
> 1. Загрузи файлы `yamo-linux`, `веб_рамка.ямо` и папку `static` на сервер в одну директорию (например, через FTP или файловый менеджер хостинга).
> 2. Подключись к серверу по SSH.
> 3. Перейди в папку с файлами.
> 4. Сделай файл исполняемым (это нужно сделать один раз):
>    ```bash
>    chmod +x yamo-linux
>    ```
> 5. Запусти сервер:
>    ```bash
>    ./yamo-linux веб_рамка.ямо
>    ```
> 6. Готово! Сайт доступен по адресу: `http://твой-ip-адрес:8080`
> 
> **Особенности этой версии:**
> - Полностью автономный бинарник (совместим с Ubuntu 22.04+).
> - Поддерживает HTTPS запросы наружу (`http_получить` / `http_отправить`).
> - Автоматически раздает CSS/JS из папки `static/`.
> - Устойчив к ошибкам: не падает при некорректных данных.
