# YAMO v2026.09.28: Production Release

## 🚀 Что нового?
Этот релиз знаменует переход языка ЯМО из статуса "экспериментальный интерпретатор" в статус **"Production-Ready Web Platform"**.

### 1. Нативная поддержка Веба (HTTP Server)
ЯМО теперь умеет открывать порты TCP/IP напрямую через системные вызовы ОС, без внешних зависимостей.
*   **Функции:** `сеть_открыть(порт)`, `сеть_принять(дескриптор)`, `сеть_прочитать(дескриптор, размер)`, `сеть_написать(дескриптор, данные)`, `сеть_закрыть(дескриптор)`.
*   **Пример:** Вы можете написать полноценный веб-сервер на чистом русском языке за 20 строк кода.

### 2. Полная кроссплатформенность
Один и тот же исходный код `.ямо` работает идентично на трех основных платформах:
*   **Windows:** Использует WinSock2 API.
*   **Linux:** Использует BSD Sockets.
*   **macOS/Unix:** Совместим с Linux-ядром сокетов.

### 3. Стабильность ООП и Памяти
Прошли комплексные стресс-тесты:
*   Создание 50,000+ объектов класса одновременно.
*   Глубокая рекурсия (факториалы, деревья).
*   Изоляция памяти между экземплярами классов.
*   Отсутствие утечек при циклических вызовах сетевых функций.

### 4. SQLite ORM Интеграция
Встроенная поддержка баз данных:
*   `бд_открыть`, `бд_запрос`, `бд_выбрать`, `бд_закрыть`.
*   Возврат результатов SELECT в виде массива словарей для удобной обработки.

## ⚙️ Быстрый старт

### На Windows
1. Откройте CMD или PowerShell в папке с `yamo.exe`.
2. Создайте файл `server.yamo`:
   ```ямо
   функция запустить() {
       целое мастер = сеть_открыть(8080);
       пока (истина) {
           целое клиент = сеть_принять(мастер);
           текст req = сеть_прочитать(клиент, 4096);
           текст html = "<h1>Привет от ЯМО!</h1>";
           текст ans = "HTTP/1.1 200 OK\r\nContent-Length: " + в_текст(длина(html)) + "\r\n\r\n" + html;
           сеть_написать(клиент, ans);
           сеть_закрыть(клиент);
       }
   }
   запустить();
   ```
3. Запустите: `.\yamo.exe server.yamo`
4. Откройте браузер: `http://localhost:8080`

### На Linux / macOS
1. Загрузите `yamo-linux` (или `yamo-unix`) на сервер.
2. Дайте права на исполнение: `chmod +x yamo-linux`
3. Запустите: `./yamo-linux server.yamo`
4. Сервер доступен по IP вашего сервера на порту 8080.

## 🛡️ Безопасность и Надежность
*   **Обработка ошибок:** Любая ошибка в C++ ядре (например, закрытый порт) приводит к понятному сообщению об ошибке в консоли, а не к падению всего процесса.
*   **Типизация:** Строгая статическая типизация предотвращает большинство runtime-ошибок еще на этапе парсинга.
