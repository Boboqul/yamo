# ИНСТРУКЦИЯ ПО ЗАПУСКУ ЯМО v2026.09.24

## Что внутри?
1. **yamo.exe** — Интерпретатор для Windows 10/11 (x64).
2. **yamo-linux-x64** — Готовый интерпретатор для Linux (x86-64).
3. **build_yamo.sh** — Скрипт для сборки под Linux/macOS из исходников.
4. **библиотека/** — Содержит `стандартная.ямо` (Ядро языка).

## Быстрый старт

### Windows
Просто запускай:
```cmd
.\yamo.exe test.yamo
```

### Linux (Готовый бинарник)
Если у тебя x86-64 Linux:
```bash
chmod +x yamo-linux-x64
./yamo-linux-x64 test.yamo
```

### Linux/macOS (Сборка из исходников)
Если нужен бинарник под другую архитектуру (ARM) или свежая версия:
1. Положи исходные файлы (.cpp, .h, sqlite3.c) в папку `./source`.
2. Запусти скрипт сборки:
```bash
chmod +x build_yamo.sh
./build_yamo.sh
```
*Внимание:* Скрипт автоматически использует `cc` для SQLite и `g++` для остального кода, чтобы избежать ошибок компиляции.
